## 📂 Folder Structure
The solutions are categorized by problem rating to keep the repository clean and easy to navigate. (Note: Folders are prefixed with `rating-` to ensure compatibility with Java packages).

- `/rating-800` 
- `/rating-900`
- `/contests`

Each file is typically named after the problem's contest ID and index (e.g., `158A_NextRound.java`).
